# Triage labels

The skills use five triage roles. Map each role to the label used in this repository.

| Skill role | Repository label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Waiting for more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Ready for an unattended agent to work. |
| `ready-for-human` | `ready-for-human` | Needs a person to implement it. |
| `wontfix` | `wontfix` | The issue will not be acted on. |

Use the repository label that matches the role when a skill asks for a triage label.
